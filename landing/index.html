DSH Mobile (DSH Orbit & Desktop Remote)

Điều khiển DeepSeek Harness từ xa trên điện thoại, trình duyệt Web và máy tính khác

Android iOS Web App Desktop Remote

Máy tính hoặc server chạy DeepSeek Harness đảm nhận toàn bộ việc thực thi; bạn mở điện thoại, trình duyệt trên iPad/laptop phụ, hoặc một cửa sổ DSH Desktop khác để theo dõi tiến độ, chat tiếp, gửi file và duyệt lệnh từ bất cứ đâu.

  • Theo dõi phiên làm việc theo thời gian thực: xem đúng danh sách workspace và phiên đang chạy trên máy chủ (kể cả các phiên tác tử con sub-agent), lọc và tìm kiếm nhanh trên mọi thiết bị.
  • Đọc hội thoại, gửi chỉ dẫn & truyền file từ xa: hiển thị đầy đủ Markdown, khối code, kết quả chạy công cụ; gửi prompt tiếp theo, đính kèm file sang máy đích (trên Desktop) và tự gửi lại tin nhắn nếu rớt mạng.
  • Duyệt hoặc từ chối lệnh trong 1 chạm: nhận thông báo đẩy khi agent dừng chờ xin chạy shell, sửa file hoặc hỏi thêm thông tin để bấm Allow once / Reject ngay từ điện thoại, trình duyệt hoặc máy phụ.
  • Gộp nhiều máy trạm & server vào một cửa sổ DSH Desktop: chuyển tức thì giữa tab This Computer và Remote Workspace ngay trên thanh bên gốc của DSH; mất mạng tạm thời vẫn giữ danh sách phiên và đọc được lịch sử lưu đệm.
  • Chạy đa nền tảng không phụ thuộc chợ ứng dụng: dùng app native trên Android & iOS (React Native + Expo SDK 58; bản ký App Store iOS đang chờ), hoặc mở thẳng bản Web App (PWA) trên trình duyệt qua mạng riêng Tailscale.
  • Tạo phiên mới, chọn model & kiểm soát thiết bị tập trung: khởi tạo phiên từ xa, đổi model, ghép đôi bằng mã QR / mã 5 phút và thu hồi quyền từng thiết bị tức thì trong Settings → Devices (bảo vệ sẵn bằng ghim chứng chỉ TLS, Face ID/vân tay hoặc Passkey).

Repo Wiki

@dsh-ext/dsh-wiki v0.3.3 · Plugin DSH + MCP

Tự động đọc mã nguồn dự án và dựng thành một website tài liệu kiến trúc kiểu DeepWiki lưu ngay trong thư mục .dsh-wiki/ trên máy bạn — không tải bất kỳ dòng code nào lên mạng.

  • Tạo trọn bộ wiki chỉ với /wiki generate: lập cây mục lục, viết bài giải thích từng module, vẽ sơ đồ kiến trúc Mermaid và xuất ra 1 file HTML tự chứa đọc offline (sáng/tối, tìm kiếm toàn văn).
  • Trích dẫn file:dòng được kiểm tra tự động: mọi mô tả đều gắn kèm đường dẫn file và số dòng thật trong repo; bước self-check báo lỗi ngay nếu trích dẫn sai hoặc lệch dòng.
  • Thẻ tóm tắt (Knowledge Cards) & cập nhật theo git diff: lọc nhanh từng API/module dạng thẻ; khi code thay đổi chỉ cần cập nhật lại đúng những trang bị ảnh hưởng.
  • 5 công cụ tra cứu cho DSH & MCP cho Claude Code / VS Code: cung cấp wiki_search, wiki_page, wiki_cards, wiki_impact, wiki_status để AI nắm bản đồ dự án và biết ngay wiki còn mới hay đã cũ.

DSH for VS Code

VS Code Extension · ACP v1 · Node ≥ 22

Tích hợp DeepSeek Harness trực tiếp vào VS Code theo mô hình của Claude Code: vừa viết code vừa giao việc cho agent và kiểm duyệt từng dòng thay đổi ngay trong trình soạn thảo.

  • Khung chat mở thành tab Editor hoặc thanh bên phải: dùng chung bảng màu và biểu tượng gốc của VS Code, thu gọn bước suy nghĩ/gọi tool thành 1 dòng để dễ theo dõi hội thoại.
  • Xem trước Diff thật & Hoàn tác cả lượt chạy: mở bảng so sánh diff gốc của VS Code trước khi cho phép sửa file; tự lưu snapshot đầu lượt để bấm Revert là khôi phục sạch.
  • Tự động gửi ngữ cảnh đang code cho Agent: đính kèm file đang mở, vùng code đang bôi đen và danh sách lỗi Diagnostics thông qua máy chủ IDE MCP nội bộ.
  • Kết nối qua chuẩn ACP v1 bền vững: chạy tiến trình dsh --profile acp độc lập để không bị gãy khi nâng cấp DSH; đang hoàn thiện tính năng nối tới máy chủ từ xa qua gateway.

Bật Host Gateway trên máy chủ

Mặc định gateway chỉ lắng nghe tại 127.0.0.1 cho tới khi bạn bật kết nối LAN/VPN có TLS. Cài plugin mobile-gateway và chọn chế độ Persistent trong phần Devices.

plugin config · mobile-gateway
gatewayMode: persistent
requireAuth: true
endpoints:
  - ws://127.0.0.1:3081/ws/mobile

Mỗi mã ghép đôi chỉ dùng được 1 lần và tự hết hạn sau 5 phút.

Kết nối từ bên ngoài

Cài Tailscale để điều khiển Host qua Internet

Hướng dẫn ngắn gọn, thực tế bằng Tailscale — Host vẫn chỉ nghe nội bộ; bạn không mở cổng ra Internet, không dùng relay công cộng.

1

Cài Tailscale trên máy chạy DeepSeek Harness

Tải và cài theo đúng hệ điều hành của Host (Windows/macOS/Linux) tại https://tailscale.com/download, sau đó đăng nhập cùng tài khoản Tailnet với các thiết bị của bạn.

2

Bật VPN trên điện thoại / laptop / máy phụ

Cài Tailscale trên iOS, Android, Windows, macOS hoặc Linux phụ rồi bật kết nối; mọi thiết bị phải cùng Tailnet. Không cần IP công cộng hay mở port trên router.

3

Cấu hình Gateway & PWA nội bộ Tailnet

Chạy Gateway TLS trên Host và trỏ WSS của PWA qua cùng một origin HTTPS của Tailscale (*.ts.net). Chỉ route /ws/mobile tới Gateway; thêm origin chính xác của PWA vào allowedOrigins để WebAuthn hoạt động.

4

Ghép đôi từ xa & kiểm tra kết nối

Trên Host mở Settings → Devices → Allow connections → tạo mã ghép đôi 5 phút. Nhập địa chỉ <tên-máy>.ts.net:<cổng> trên thiết bị điều khiển (app native có thể dùng QR), bấm Approve trên desktop; thử xem danh sách phiên và gửi một lệnh nhỏ.
